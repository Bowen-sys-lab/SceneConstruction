# 温度与红外材料配置

## 三个概念

- RGB 材质：决定可见光画面中的颜色、贴图和外观；
- 红外材料：决定热成像中的发射率、反射和材料响应；
- 温度目标：决定物体的表面温度设定。

同一个物体通常同时需要 RGB 材质和红外材料。

## 温度模式

```yaml
targets:
  background:
    mode: fixed
    temperature_c: 18.0

  warm_object:
    mode: ambient

  relative_object:
    mode: offset
    offset_c: 8.0
```

- `fixed`：使用指定摄氏温度；
- `ambient`：跟随环境空气温度；
- `offset`：使用空气温度加上偏移量。

这些温度通常属于仿真设定，除非有实测依据，不应表述为真实测量值。

## 常用红外材料

材料名称需要来自当前 irsim 材料库。常用名称包括：

| 材料 | 常见对象 |
|---|---|
| `concrete` | 混凝土地面、建筑结构 |
| `asphalt_dry` | 干燥沥青道路 |
| `brick_wall` | 砖墙 |
| `vegetation_leaf` | 树叶、绿化 |
| `car_paint_black` | 黑色车辆外壳 |
| `car_paint_white` | 白色车辆外壳 |
| `glass_windshield` | 玻璃、车窗 |
| `aircraft_aluminium_painted` | 涂漆金属设备 |
| `bare_aluminium` | 裸露铝金属 |
| `painted_composite` | 涂漆复合材料 |
| `abs_plastic_white` | 白色塑料 |
| `soil_dry` | 干燥土壤 |
| `water` | 水面 |

如果场景需要新增材料，记录其来源和用途，并保持材料名称的一致性。

## 绑定规则

```yaml
bindings:
  - name: target_hotspot
    prim_path: /World/Site/Target_001
    include_children: true
    target: target_hotspot
    material: bare_aluminium
```

- `prim_path` 区分大小写；
- `include_children: true` 会覆盖子网格；
- 复杂物体的热点适合绑定到更具体的路径；
- 没有特殊温差的对象可以使用默认值；
- 目标、热点、玻璃、金属和车辆不宜全部使用同一种红外材料。

## 配置关系

```text
先确定物体 → 再确定温度目标 → 再选择红外材料 → 最后写绑定
```

# 电脑环境检查

RGB + Thermal 预览依赖本机已有的 Isaac Sim 项目环境。首次使用前，可以先运行：

```powershell
.\tools\preflight_environment.ps1 `
  -ProjectRoot D:\IsaacSim_Demo `
  -IsaacRoot D:\isaacsim `
  -SceneConfig D:\IsaacSim_Demo\configs\your_scene.yaml
```

脚本会检查：

- Isaac Sim 根目录和 `python.bat`；
- 项目根目录；
- RGB + Thermal 启动脚本；
- 项目中的 `irsim` 源码目录；
- USD 运行时扩展；
- 场景配置的基本字段；
- 场景配置引用的文件；
- `irsim` Python 导入情况。

只有必需项全部通过时，才适合继续启动预览。黄色警告表示路径或导入状态需要进一步确认，不一定阻止预览。

如果只需要检查文件，不运行 Python 导入，可以使用：

```powershell
.\tools\preflight_environment.ps1 `
  -ProjectRoot D:\IsaacSim_Demo `
  -IsaacRoot D:\isaacsim `
  -SceneConfig D:\IsaacSim_Demo\configs\your_scene.yaml `
  -SkipImportCheck
```

每台电脑的 Isaac Sim 安装目录和项目目录可以不同，使用参数指定实际位置即可。

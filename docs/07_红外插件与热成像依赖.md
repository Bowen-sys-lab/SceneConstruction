# 红外插件与热成像依赖

RGB + Thermal 预览依赖项目现有的红外相机仿真插件：

```text
仓库名称：isaac-thermal-camera-simulation
Python 包：irsim
Isaac Sim 适配层：irsim_isaac
```

项目默认从下面的位置加载它：

```text
D:\IsaacSim_Demo\third_party\isaac-thermal-camera-simulation
```

这个插件负责把场景中的表面温度、红外材料、环境辐射和相机模型转换成热成像结果。它不是 RGB 贴图，也不是 Isaac Sim 自带的普通可见光材质。

## 配置中的关系

场景配置通常包含：

```yaml
sensors:
  sensor_config: ../third_party/isaac-thermal-camera-simulation/configs/sensors/flir_boson_640_lwir.yaml
  thermal_config: thermal.yaml
```

其中：

- `sensor_config`：红外相机模型，默认是 FLIR Boson 640 LWIR；
- `thermal_config`：当前场景中各个 Prim 的红外材料和温度绑定；
- `display_config`：热图显示范围，只影响显示，不改变原始热成像数据。

## 电脑环境要求

预览电脑需要同时具备：

1. Isaac Sim；
2. 项目根目录；
3. `third_party/isaac-thermal-camera-simulation/src`；
4. `irsim` 所需的配置和材料目录；
5. 项目中的双相机预览脚本。

可以先运行环境检查：

```powershell
.\tools\preflight_environment.ps1 `
  -ProjectRoot D:\IsaacSim_Demo `
  -IsaacRoot D:\isaacsim `
  -SceneConfig D:\IsaacSim_Demo\configs\your_scene.yaml
```

其中 `irsim import PASS` 表示 Python 可以找到红外仿真核心。预检失败时，Thermal 画面不能正常生成，应先处理环境问题。

## 运行边界

这个工作包只引用项目已有的红外插件，不复制、修改或重新打包插件源码。新场景只需要在 `thermal.yaml` 中引用有效的红外材料名称，并在 `scene.yaml` 中指向相应的传感器配置。

如果电脑上只有 Isaac Sim、没有项目中的 `irsim` 目录，RGB 场景可能仍能打开，但不能得到项目所需的红外热成像结果。

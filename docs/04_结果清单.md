# 新场景结果清单

## 建议保留的文件

- [ ] 场景 USD/USDAs 文件；
- [ ] 所有 RGB 贴图；
- [ ] RGB 材质或材质说明；
- [ ] `scene.yaml`；
- [ ] `thermal.yaml`；
- [ ] `display.yaml`；
- [ ] 物体—RGB 材质—红外材料—温度绑定表；
- [ ] 资产来源和许可证说明；
- [ ] 预览截图或短视频；
- [ ] `validation_report.md`。

## 记录内容

- 场景用途；
- 场景来源；
- 场景中的主要对象；
- 目标对象或目标区域；
- 特殊温度对象；
- 热点温度和背景温度；
- 预览所使用的配置文件；
- 已知问题和未完成内容。

## 基本检查标准

- 场景能够正常打开；
- RGB 贴图能够加载；
- RGB 与 Thermal 预览均能显示；
- 目标物在 Thermal 中具有可见温差；
- 场景不依赖其他研究场景；
- 核心代码和第三方插件保持不变；
- 来源和许可证信息完整。

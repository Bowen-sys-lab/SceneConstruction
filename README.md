# SceneConstruction 场景搭建与温度配置参考

本仓库整理新场景的搭建、可见光材质配置、红外材料配置和温度设定方法。

内容覆盖场景资产、Prim 层级、RGB 材质、红外材料、温度目标、双画面预览和结果整理。飞控、双相机同步、轨迹回放、数据集设计和评测逻辑属于另一层系统，通常不需要在场景制作阶段改动。

## 一个完整场景通常包含

- 可在 Isaac Sim 中打开的 USD/USDAs 场景；
- 完整的 RGB 贴图和可见光材质；
- 清晰的 Prim 层级和物体命名；
- 场景配置 YAML；
- 红外材料与温度配置 YAML；
- 热图显示配置 YAML；
- 资产来源与许可说明；
- 物体、材质、温度绑定表；
- 预览记录和基础检查结果。

## 使用顺序

1. 阅读 `docs/01_新场景搭建步骤.md`；
2. 阅读 `docs/02_温度与红外材料配置.md`；
3. 复制 `templates/` 中的 YAML 模板；
4. 准备独立的新场景资产；
5. 按 `docs/03_RGB与红外预览.md` 查看双画面效果；
6. 按 `docs/04_结果清单.md` 整理场景和配置。

## 配置边界

场景制作通常只涉及：

- 新场景 USD/USDAs 文件；
- RGB 贴图和材质；
- 场景专属的 `scene.yaml`、`thermal.yaml`、`display.yaml`；
- 场景专属的材料目录；
- 来源、温度设定和预览记录。

现有研究场景、飞控、相机同步、回放、数据集格式、评测逻辑以及第三方红外插件源码保持独立。

## 目录说明

- `templates/`：场景配置模板；
- `starter/`：可复制的起始配置；
- `docs/`：搭建、温度配置和预览说明；
- `tools/`：双画面预览入口和基础配置检查；
- `examples/minimal_scene/`：最小示例说明；
- `SceneConstruction_SOURCE.md`：仓库来源记录。

## 预览方式

预览窗口只显示 RGB 和 Thermal 两幅图。温度、Prim 路径和调试信息不覆盖在画面上，场景效果通过画面观察和调整。配置错误在启动前以简单错误提示显示。
